# Nethmi & Kavindu — Digital Wedding Invitation

    npm install
    npm run dev

Deploy: push to GitHub and import into Vercel, no configuration needed.

Edit details in `lib/data.ts`. Add an instrumental track at `public/music.mp3` or set `NEXT_PUBLIC_MUSIC_URL`.
RSVPs post to `app/api/rsvp/route.ts`; connect it to Google Sheets, Firebase or a database.
